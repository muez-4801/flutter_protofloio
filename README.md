# 🌟 Muez Fathi - Modern Flutter Portfolio

A sleek, responsive, and beautifully designed personal portfolio built with **Flutter**, featuring **Glassmorphism**, neon gradient highlights, smooth scroll animations, and interactive components.

---

## ✨ Features

- 🎨 **Glassmorphism & Gradient UI:** Frosted glass cards with backdrop blur, borders, and modern cyberpunk gradients.
- ⚡ **Single Page Smooth Scroll:** Seamless navigation with an animated floating navbar that tracks sections automatically.
- 📱 **Cross-Platform:** Runs flawlessly on **Web**, **Windows Desktop**, **Android**, and **iOS**.
- 🛠️ **Full Portfolio Sections:**
  - **Hero:** Typing subtitle animation, pulsing glow avatar, floating background orbs, and social links.
  - **About:** Personal bio, key stats counters with hover interactions.
  - **Skills:** Categorized technical skill sets with animated level progress bars.
  - **Projects:** Interactive showcase of apps (E-Commerce, Weather, Productivity, Chat) with tech chips and hover zoom.
  - **Experience & Education:** Vertical glowing timeline detailing academic and professional milestones.
  - **Contact:** Interactive contact cards, custom vector brand icons, and footer.

---

## 🚀 Tech Stack

- **Framework:** [Flutter](https://flutter.dev) (Dart SDK 3.13+)
- **Typography:** [Google Fonts](https://pub.dev/packages/google_fonts) (Poppins, Fira Code)
- **Utilities:** [url_launcher](https://pub.dev/packages/url_launcher)

## 💻 Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed and configured in PATH.

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/muezfathi/flutter_portfolio.git
   cd flutter_portfolio
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run on Chrome (Web):**
   ```bash
   flutter run -d chrome
   ```

4. **Run on Windows Desktop:**
   ```bash
   flutter run -d windows
   ```

5. **Build for production (Web):**
   ```bash
   flutter build web
   ```
